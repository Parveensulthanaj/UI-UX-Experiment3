# UI-UX-Experiment3

## Aim:
To design a premium, mobile-first OTT streaming app interface called VYBE. It should let users discover, watch and download content with minimal effort, using a consistent dark visual style.

## Objectives
1.Design the main user flow: browse → select title → play → download for offline viewing.

2.Create a consistent visual identity (colour, type, spacing, icons).

3.Keep navigation simple with a bottom tab bar and large touch targets (44px or more).

4.Meet accessibility basics: readable contrast, labelled icon buttons, clear focus order.

5.Produce high-fidelity screens that a developer can build from.

## Algorithm:

1. Define users and goals (watch quickly, resume, download offline)
2. List the core screens: Home, Title Detail, Player, Downloads
3. Sketch the flow: Home → Detail → Player; Home → Downloads
4. Choose the design system: dark palette, violet accent, two typefaces
5. FOR each screen:
       build layout on a 390 × 844 artboard
       add components (hero, rows, buttons, nav bar)
       check contrast and touch-target size
   END FOR
6. Link the screens into one flow
7. Review and refine
8. Export the screens (PDF or image)
END

4.The design is ready for developer hand-off or for converting into a clickable prototype.
